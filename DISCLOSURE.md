# Disclosure and evidence policy

This repository contains an anonymized case study based on an explicitly authorized security assessment.

## Withheld information

The following information is intentionally excluded:

- application and organization names;
- owner, developer, and user identities;
- domains, endpoints, and source repositories;
- Firebase project IDs, app IDs, API keys, buckets, UIDs, and document IDs;
- authentication tokens, cookies, authorization headers, and App Check values;
- exact timestamps and content that could correlate with private logs;
- complete reusable payloads;
- screenshots containing the target's original visual identity.

## Evidence handling

The public images are sanitized reconstructions derived from private evidence. They show only the security-relevant behavior and are clearly labeled as reconstructions. Original screenshots remain private and are not part of this repository or its Git history.

## Testing constraints

- Only tester-controlled disposable accounts were used.
- Proofs of concept used benign visual markers.
- No credentials or session data were collected.
- No destructive or availability-impacting action was performed.
- No administrator, account, or server takeover is claimed.

## Contact

Questions about this case study can be opened as a GitHub issue. Details that could identify the target will not be discussed publicly.
