## Documentation approach

Record scope, authorization, evidence, root causes, and remediation. Distinguish confirmed findings from observations and label partially reconstructed notes. Keep credentials, private identifiers, and personal data out of published reports.

Read the [disclosure policy](DISCLOSURE.md) and use the [writeup template](templates/WRITEUP_TEMPLATE.md). English is the primary language; the Firebase case study also retains its Portuguese summary.
